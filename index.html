LOGIKA

Урок 1 — Основні теги

<html>
Визначає кореневий елемент HTML-документа. Усі інші елементи мають бути всередині цього тегу.
<head>
Містить службову інформацію про сторінку: назву, стилі, скрипти, метадані. Не відображається на екрані.
<meta>
Тег для метаінформації: кодування тексту, опис сторінки, ключові слова, адаптивність.

Урок 2 — Структура сторінки

<body>
Містить весь вміст сторінки, який бачить користувач: текст, картинки, кнопки, таблиці.
<h1> – <h6>
Заголовки різного рівня. <h1> — найголовніший, <h6> — найменший.
<title>
Визначає назву вкладки браузера. Не відображається в тексті сторінки.

Урок 3 — Текстові теги

<p>
Визначає абзац тексту. Використовується найчастіше для основного текстового контенту.
<br>
Робить перенос рядка. Не створює новий абзац, лише перенос.
<strong>
Виділяє важливий текст, робить його жирним і логічно значущим.
<em>
Виділяє текст курсивом і підкреслює його важливість.

Урок 4 — Зображення та посилання

<img>
Додає зображення на сторінку. Потрібен атрибут src для вказання шляху.
<a>
Створює посилання. Атрибут href задає адресу переходу.
<button>
Створює кнопку. Може виконувати функції через JavaScript.

Урок 5 — Блокові елементи

<div>
Контейнер для групування елементів. Часто використовується в розмітці.
<span>
Використовується для виділення частини тексту або inline-елементів.
